# Segurança

Correções de segurança serão aplicadas à versão mais recente do Transcribe. Mantenha o aplicativo atualizado pelos downloads deste repositório.

## Reportar uma vulnerabilidade

Use [Report a vulnerability](https://github.com/listiago/transcrit/security/advisories/new) para enviar um relato privado ao mantenedor. Inclua a versão afetada, os passos para reproduzir com dados fictícios e o impacto esperado.

Não publique uma vulnerabilidade ainda não corrigida em uma Issue pública. Não envie chaves de API, áudio pessoal, transcrições ou arquivos de perfil. Se uma chave tiver sido exposta, revogue-a na conta do provedor e gere outra.

## Distribuição

Os instaladores oficiais deste projeto ficam em [GitHub Releases](https://github.com/listiago/transcrit/releases). Cada versão inclui `SHA256SUMS.txt` para verificar a integridade dos arquivos. Checksums não substituem assinatura de código nem notarização; esta distribuição ainda não possui essas credenciais comerciais.
