# Transcribe 1.2.3

Primeira distribuição pública do Transcribe: ditado minimalista para Windows e macOS, com código aberto sob licença MIT.

- Minicard flutuante com microfone, parar, arraste e fechar.
- Atalho global: **Ctrl + Shift + Espaço** no Windows e **⌘ + Shift + Espaço** no Mac.
- **Enter** termina e **Esc** cancela; o app não envia mensagens automaticamente.
- Transcrição com `gpt-transcribe`, usando a chave OpenAI de cada pessoa.
- Inserção no campo de origem, histórico local criptografado e importação/exportação de texto.
- Corrigido o bloqueio de cliques ao fechar e reabrir o card pelo atalho no Windows.

## Escolha seu download

- **Windows 10+ x64:** `Transcribe-Setup-1.2.3-x64.exe`.
- **macOS 13+, Apple Silicon:** `Transcribe-1.2.3-macOS-arm64.dmg`.
- **macOS 13+, Intel:** `Transcribe-1.2.3-macOS-x64.dmg`.
- Os ZIPs contêm o aplicativo para cada arquitetura do Mac. `SHA256SUMS.txt` permite conferir a integridade dos downloads.

## Antes de usar

É necessária internet, permissão de microfone e uma chave OpenAI com saldo e acesso ao modelo. O uso da API é cobrado separadamente da assinatura ChatGPT. No Mac, a inserção em outros aplicativos também precisa de Acessibilidade e, quando solicitado, Automação.

Os instaladores ainda não têm assinatura comercial no Windows nem Developer ID/notarização da Apple. O sistema pode exibir avisos ou bloquear a primeira abertura. Consulte as instruções no README, sem desativar as proteções do sistema.

O fluxo de ditado foi validado no Windows. Os pacotes Mac são compilados no GitHub Actions para as duas arquiteturas, mas o ditado em um Mac físico ainda não foi validado; suporte experimental nesta versão. Não há atualização automática.
